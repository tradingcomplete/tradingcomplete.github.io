🔒 締め処理タイプ

📅

月次締め

毎月のトレードを確定。変更不可にして記録を保護。

📊

四半期締め

3ヶ月分をまとめて締め。四半期レポート作成に便利。

📈

年次締め

年間の全取引を確定。確定申告の準備が完了。

🚀 主要機能

  • ✓

    経費管理

    トレードに関連する経費を日付・カテゴリ別に管理。年間の必要経費を正確に把握できます。

  • ✓

    一括入力機能

    複数のトレードをまとめて入力。CSVからのコピペや、定型パターンの保存も可能。

  • ✓

    締め処理

    期間を確定させることで、誤って過去のデータを変更することを防止。監査証跡としても有効。

  • ✓

    収支サマリー

    トレード損益、経費、純利益を自動計算。税金計算に必要な数字が一目でわかります。

  • ✓

    FX業者照合

    FX業者の年間損益報告書と照合可能。差異があれば即座に発見できます。

  • ✓

    編集・削除制限

    締め処理後は編集不可。確定申告の信頼性を高め、税務調査にも対応。
