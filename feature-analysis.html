統計分析機能

トレード履歴を多角的に分析し、成長のヒントを見つける機能。「なんとなく」を「データで裏付けられた強み」に変換します。

📸 画面イメージ

分析タブは大きく4つのエリアで構成されています。統計サマリーで全体像を把握し、レポート生成で詳細を確認、チャート表示で視覚的に理解するという流れで、多角的な分析が可能です。

統計ダッシュボード - 重要指標を一目で把握。総トレード数、勝率、総獲得Pipsなどをリアルタイム表示

月次レポート - 通貨ペア別・曜日別の詳細分析結果を自動生成。強み・弱みが一目瞭然

パフォーマンスチャート - 月別推移と累積損益を美しいグラフで視覚化。成長の軌跡を実感

📈 分析可能な主要指標

統計サマリーエリアに常時表示される重要指標です。Pips表示と円建て表示を切り替えることで、技術面と収支面の両方を把握できます。

💡 表示切替で技術面と収支面を両方確認

ワンクリックで切り替え可能。技術向上には「Pips表示」、実際の収支確認には「円建て表示」を活用。

🚀 主要機能と活用方法

  • ✓

    リアルタイム統計自動計算

    総トレード数、勝敗数、勝率、平均獲得Pips、連勝・連敗記録など、重要な統計を自動計算。トレードを記録するだけで、常に最新の成績が確認できます。データに基づいた改善ポイントの発見に役立ちます。

  • ✓

    Pips/円建て両対応の切替表示

    Pips表示で純粋なトレード技術を評価し、円建て表示で実際の収益を正確に把握。ロット数の影響を受けずに技術向上を測りながら、実際の収支も確認できる二刀流の分析が可能です。

  • ✓

    4種類の自動レポート生成

    週次、月次、四半期、年次の4パターンでレポートを自動生成。短期的な調整から長期的な成長確認まで、目的に応じた振り返りが可能。PDFエクスポートで記録の保存も簡単です。

  • ✓

    美しいグラフで視覚的に理解

    月別パフォーマンス、累積損益、通貨ペア別分析を直感的なグラフで視覚化。数字だけでは分からない傾向やパターンを発見し、成長の軌跡を実感できます。

  • ✓

    通貨ペア別・時間帯別の詳細分析

    どの通貨ペアが得意で、どの時間帯・曜日が勝率が高いかを明確化。自分の強みを活かし、弱点を避けるトレード戦略の最適化に活用できます。データドリブンな意思決定をサポートします。

  • ✓

    フィルター機能で深掘り分析

    期間、通貨ペア、売買方向などで絞り込んで分析。「ロングは得意だけどショートが苦手」「特定の通貨ペアで負けが多い」といった具体的な課題を発見し、ピンポイントで改善できます。
