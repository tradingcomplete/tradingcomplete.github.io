🚀 主要機能

  • ✓

    日次記録

    毎日の相場の動き、重要な指標発表、自分の感情や気づきを自由に記録。後から振り返る際の貴重な資料に。

  • ✓

    リッチテキストエディタ

    見出し、太字、リスト機能を使って見やすく整理。重要な部分を強調して記録できます。

  • ✓

    画像添付

    チャート画像や経済指標のスクリーンショットを添付。文字だけでは伝わらない情報も保存。

  • ✓

    週間プレビュー

    現在の週の記録状況を一目で確認。記録の習慣化をサポートします。

  • ✓

    カレンダー表示

    月間カレンダーで記録済みの日をビジュアル表示。記録の継続性が一目瞭然。

  • ✓

    検索機能

    過去のノートをキーワード検索。特定の相場状況や気づきをすぐに見つけられます。
