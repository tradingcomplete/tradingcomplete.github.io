📂 出力可能なデータ

📊
月別CSV

指定月のトレード記録と経費をまとめて出力。月次レポート作成に最適。

📈
年次トレードCSV

年間の全トレード記録を一括出力。確定申告の基礎資料として活用。

💰
年次経費CSV

年間の経費をカテゴリ別に出力。必要経費の申告に必須。

📋
年間サマリー

年間収支の総括レポート。損益、経費、純利益を一目で把握。

🚀 主要機能

  • ✓

    期間指定出力

    月単位、四半期単位、年単位での出力が可能。必要な期間のデータだけを抽出できます。

  • ✓

    Excel完全対応

    BOM付きUTF-8形式で出力。Excelで開いても文字化けせず、そのまま編集可能。

  • ✓

    カスタマイズ可能

    出力する項目を選択可能。必要な情報だけを含めたCSVファイルを作成。

  • ✓

    確定申告対応

    税務申告に必要な形式で出力。FX業者の年間損益報告書と照合しやすい形式。

  • ✓

    経費統合出力

    トレード損益と経費を統合したレポート出力。純利益の計算が簡単。

  • ✓

    バックアップ機能

    全データのCSV出力でバックアップ作成。データ移行や保管に便利。
