利用規約・プライバシーポリシー

制定日：2026年3月8日

この利用規約（以下「本規約」）は、コンパナ（以下「当方」）が提供するWebサービス「Trading Complete」（以下「本サービス」）の利用条件を定めるものです。本サービスをご利用になる前に、必ず本規約をお読みください。

第1条（規約への同意）

ユーザーは、本サービスに登録または利用を開始した時点で、本規約の全内容に同意したものとみなします。

第2条（サービスの内容）

本サービスは、FXトレードの記録・分析・収支管理を支援するWebアプリケーションです。主な機能は以下のとおりです。

  • トレード記録・分析機能
  • 相場ノート機能
  • 収支管理・CSV出力機能
  • クラウドデータ同期機能（Proプラン以上）
  • その他当方が提供する機能

第3条（アカウント登録）

  1. 本サービスの利用にはアカウント登録が必要です。
  2. ユーザーは正確な情報を登録する義務を負います。
  3. アカウントの管理はユーザー自身の責任において行うものとします。
  4. 第三者へのアカウントの譲渡・貸与は禁止します。
  5. アカウントの不正利用が判明した場合、当方はアカウントを停止または削除できるものとします。

第4条（料金・支払い）

  1. Freeプランは無料でご利用いただけます。
  2. 有料プラン（Pro・Premium）の料金は、サービス内に表示する金額（税込）とします。
  3. 支払いはクレジットカードによる自動更新方式です。決済処理はStripeが行い、カード情報は当方のサーバーには保存されません。
  4. 料金は毎月または毎年の契約更新日に自動決済されます。
  5. 当方は料金を変更する場合、事前にユーザーへ通知します。

第5条（解約・返金）

  1. ユーザーはいつでもサービス内の「プラン管理」から解約できます。
  2. 解約後は契約期間終了日まで有料機能を継続してご利用いただけます。
  3. 期間終了後は自動的にFreeプランに移行します。
  4. サービスの性質上、決済済みの料金の返金は原則として行いません。ただし、当方の重大な過失によりサービスが利用できなかった場合はこの限りではありません。

第6条（禁止事項）

ユーザーは以下の行為を行ってはなりません。

  • 法令または公序良俗に違反する行為
  • 当方または第三者の知的財産権・プライバシー・名誉を侵害する行為
  • 本サービスの運営を妨害する行為（不正アクセス、過度な負荷をかける行為等）
  • 他のユーザーになりすます行為
  • 本サービスのリバースエンジニアリング、改ざん、複製等
  • その他当方が不適切と判断する行為

第7条（知的財産権）

本サービスに関する著作権その他一切の知的財産権は当方に帰属します。ユーザーが本サービスに入力・記録したデータの著作権はユーザーに帰属します。

第8条（サービスの変更・停止）

  1. 当方はユーザーへの事前通知なく、本サービスの内容を変更・追加・削除できるものとします。
  2. メンテナンスや障害等によりサービスが一時停止する場合があります。
  3. 当方はサービス停止・変更によって生じた損害について、責任を負いません。

第9条（データの取り扱い）

  1. ユーザーのデータはプライバシーポリシーに従って取り扱います。
  2. アカウントを削除した場合、ユーザーデータは一定期間後に削除されます。
  3. 当方はバックアップに努めますが、データの完全な保全を保証するものではありません。重要なデータはCSV出力機能等でバックアップすることをお勧めします。

第10条（免責事項）

  1. 本サービスは現状有姿で提供されます。特定目的への適合性・完全性・正確性を保証するものではありません。
  2. 本サービスはFXトレードの投資成果を保証するものではありません。投資はご自身の判断と責任で行ってください。
  3. 当方は、本サービスの利用によって生じた損害について、当方の故意または重大な過失による場合を除き、責任を負いません。

第11条（規約の変更）

当方は必要に応じて本規約を変更できます。重要な変更を行う場合は、サービス内または登録メールアドレスへの通知をもって告知します。変更後の利用規約に同意できない場合は、サービスの利用を停止してください。

第12条（準拠法・管轄裁判所）

本規約は日本法に準拠します。本サービスに関する紛争については、当方の所在地を管轄する裁判所を第一審の専属的合意管轄裁判所とします。

コンパナ（以下「当方」）は、「Trading Complete」（以下「本サービス」）において収集するユーザーの個人情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

第1条（収集する情報）

本サービスでは以下の情報を収集します。

1. ユーザーが提供する情報

  • メールアドレス（アカウント登録時）
  • パスワード（ハッシュ化して保存）
  • ユーザー名・プロフィール情報
  • トレード記録・相場ノート・収支データ等（ユーザーが入力したデータ）

2. 自動的に収集される情報

  • IPアドレス・ブラウザ情報・デバイス情報
  • アクセス日時・閲覧ページ・操作ログ
  • Google Analyticsによるアクセス解析データ（匿名）

3. 決済情報

クレジットカード情報はStripeが直接収集・管理します。当方のサーバーにはカード番号等の決済情報は保存されません。当方が保持するのは、StripeのCustomer IDおよびSubscription IDのみです。

第2条（情報の利用目的）

  • 本サービスの提供・維持・改善
  • ユーザーサポート・お問い合わせへの対応
  • サービスに関する重要なお知らせの送信
  • 利用規約違反の調査・対応
  • サービスの利用状況の分析（匿名化した形で行います）

第3条（第三者への提供）

当方は以下の場合を除き、ユーザーの個人情報を第三者に提供しません。

  • ユーザーの同意がある場合
  • 法令に基づき開示が必要な場合
  • 人の生命・身体・財産の保護のために必要な場合

第4条（業務委託先（サブプロセッサー））

本サービスは以下のサービスを利用しており、必要な範囲でデータが処理されます。

  • Supabase（米国）：認証・データベース・ファイルストレージ
  • Stripe（米国）：決済処理・サブスクリプション管理
  • Google Analytics（米国）：アクセス解析（匿名化・集計データのみ）
  • GitHub Pages（米国）：Webホスティング

各サービスのプライバシーポリシーに従ってデータが取り扱われます。

第5条（Cookieの使用）

本サービスはCookieおよびローカルストレージを使用します。

  • 認証情報の保持：ログイン状態の維持のために使用
  • アプリ設定の保存：テーマ設定等のローカル保存
  • アクセス解析：Google AnalyticsによるCookie（匿名）

ブラウザの設定によりCookieを無効にできますが、一部機能が正常に動作しなくなる場合があります。

第6条（データの保存期間）

  • アカウントが有効な期間中、ユーザーデータを保持します。
  • アカウント削除後は速やかにデータを削除します。ただし、法令上の保存義務がある場合を除きます。

第7条（セキュリティ）

当方は収集した情報を適切に保護するため、以下の対策を講じています。

  • SSL/TLS暗号化通信
  • Supabase Row Level Security（RLS）によるデータ分離
  • パスワードのハッシュ化保存
  • セッションタイムアウト管理

第8条（ユーザーの権利）

ユーザーは以下の権利を有します。

  • 開示・訂正：保有する個人情報の開示・訂正を求める権利
  • 削除：アカウント削除によりデータを削除する権利
  • データエクスポート：CSV出力機能によりデータをダウンロードする権利

これらのご要望は、下記お問い合わせ先までご連絡ください。

第9条（未成年者の利用）

本サービスは18歳以上のユーザーを対象としています。18歳未満の方が利用する場合は、保護者の同意を得てください。

第10条（プライバシーポリシーの変更）

当方は必要に応じて本ポリシーを変更できます。重要な変更を行う場合は、サービス内または登録メールアドレスへの通知をもって告知します。
